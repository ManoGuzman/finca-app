## About The Project

La Finca Tours is a modern travel agency landing page built with Next.js. It showcases travel packages, destinations, and provides a way for customers to contact the agency directly via WhatsApp or the contact form.

**Key Features:**
- Beautiful hero section with carousel showcasing destinations
- Travel packages display with pricing and details
- About section highlighting company experience
- Testimonials from satisfied customers
- Contact form for inquiries
- WhatsApp floating button for quick communication
- Fully responsive design

## Getting Started

Follow these steps to get a local copy up and running.

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [pnpm](https://pnpm.io/) (recommended)
  ```sh
  pnpm install pnpm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/ManoGuzman/finca-app.git
   ```
2. Install dependencies
   ```sh
   pnpm install
   ```
3. Run the development server
   ```sh
   pnpm dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Usage

This landing page is designed for a travel agency. You can customize:

- Hero section images and text in `src/components/HeroSection.tsx`
- Package details in `src/components/PackagesSection.tsx`
- Features in `src/components/FeaturesSection.tsx`
- Contact information in `src/components/ContactSection.tsx`
- Company information in `src/components/AboutSection.tsx`
